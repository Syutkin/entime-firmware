# Changelog

## [0.2.0] - 2026-10-19

### Added

- Добавлены host-тесты штатной работы, переходов состояний, пограничных
  значений и отказов синхронизации, событий, настроек, команд и периферии.
- Добавлены проверки управления BLE и его сервисов, действий по касаниям
  и отложенных обновлений интерфейса.
- Добавлена автоматическая сборка прошивки и проверка host-тестов с UBSan
  в CI, со статистикой по группам тестов.
- Добавлена публикация GitHub Release по тегу с описанием из changelog,
  прошивкой, полным образом и контрольными суммами SHA-256.

### Changed

- Обновлена совместимость с ESP32 Arduino Core 3 и платформой espressif32 8.
  Ограничения версий зависимостей PlatformIO сняты.
- Усилена проверка типов и диапазонов JSON-настроек до преобразования значений.
  Явный `null` отклоняется; пропущенные параметры сохраняют прежние значения.
- Пароль Wi-Fi исключён из ответа `load_config`. При сохранении отсутствие
  `wifi.passwd` сохраняет пароль, строка заменяет его, пустая строка очищает.
- Настройки touch применяются после успешного сохранения без перезагрузки.

### Fixed

- Исправлены восстановление GPS-синхронизации и сохранение UTC при переходах
  между GPS, RTC и удержанием времени без сигнала.
- Исправлены обработка пропущенных и лишних SQW-импульсов, потеря доверия
  к RTC при продолжающемся SQW и перепланирование записи RTC по PPS.
- Учтены дрейф часов ESP, задержки чтения RTC и явная коррекция его времени
  при формировании временных меток событий.
- Пакеты START/FINISH сохраняются до завершения передачи через BLE.
- Устранён перенос неполных BLE-команд между подключениями и потеря первой
  команды после таймаута слишком длинного сообщения.
- Исправлены загрузка настроек без сохранённого имени устройства и обработка
  ошибок записи и очистки NVS.
- Пароли Wi-Fi скрыты в логах команд.
- NMEA с неверной контрольной суммой больше не обновляет свежесть GPS-времени.
  Последний спутник GSV сохраняется и при пустом SNR.
- Успешный ответ `factory_reset` отправляется после постановки перезагрузки
  на таймер; ошибки таймера возвращаются вызывающей стороне.
- Исправлены обработка запоздавшего IP после отключения Wi-Fi и передача
  очищенного состояния в callback отключения.
- Состояние BLE остаётся подключённым, пока есть хотя бы один клиент.

## [0.1.1] - 2026-05-18

### Added

- Добавлена настройка `gps.enabled` для включения и отключения GPS при запуске.
- Добавлен экран спутников GPS с положением на небосводе, уровнем SNR
  и диагностикой свежести данных NMEA/GSV.
- Добавлен экран параметров питания, открываемый касанием иконки батареи.
- Добавлены прокрутка журнала загрузки касанием и анимация иконки при зарядке.

### Changed

- Часовой пояс задаётся в минутах параметром `device.timezone_offset_min`
  вместо `device.timezone`. Поддерживаются смещения от −720 до +840 минут.
- В ответе `status` поле `gps.satellites` заменено на `gps.satellites_used`
  и `gps.satellites_view`; добавлен возраст данных GSV.
- Логирование подключения Wi-Fi привязано к изменениям состояния.

### Fixed

- Исправлён возврат к GPS после восстановления PPS при расхождении фаз GPS и RTC.
- Улучшены переход на RTC после потери PPS и сохранение GPS-времени на время
  перехода; учтён выбор режима синхронизации только от RTC.
- Исключено использование устаревших NMEA и недостоверного времени RTC.
  Удержание времени RTC без стабильного SQW ограничено 30 секундами.
- Слишком длинная JSON-команда отклоняется с ошибкой `104`, её остаток
  отбрасывается до конца строки.

## [0.1.0] - 2026-05-16

### Added

- Реализованы режимы START и FINISH для ESP32-S3 с захватом внешних событий
  по прерыванию и формированием временных меток.
- Добавлены событийные пакеты START/FINISH и секундные пакеты BEEP/VOICE
  по Serial и Bluetooth Low Energy.
- Реализована синхронизация времени по GPS PPS/NMEA с резервным источником
  RTC DS3231 и обработкой SQW-импульсов.
- Добавлены синхронизация RTC по NTP через Wi-Fi, выбор источника времени
  и калибровка RTC через команды.
- Реализован JSON-протокол управления по Serial/BLE: проверка соединения,
  запрос времени и состояния, управление Wi-Fi, чтение и сохранение настроек,
  сброс к заводским настройкам.
- Добавлено хранение настроек в NVS с валидацией и частичным обновлением.
- Реализованы Nordic UART Service, Battery Service и Device Information
  Service с регистрацией через BLE-плагины.
- Добавлены интерфейс TFT ILI9341 со статус-баром, журналом загрузки,
  отображением отсечек и стартовым обратным отсчётом, а также touch-калибровка
  и обработка касаний.
- Добавлен мониторинг напряжения, тока, мощности и уровня заряда через INA226.
